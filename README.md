# 차트 발굴기 (chart_screener)

KOSPI·KOSDAQ 전 종목의 일봉을 분석해 **CAN SLIM · 컵앤핸들 · VCP · 장기횡보 후 대량거래 장대양봉 돌파 ·
300억 장대양봉 눌림목** 등 기술적 매수 패턴을 찾는 스크리너입니다. 결과는 인터랙티브 HTML 리포트
(차트 위에 패턴·피벗·손절선 표시)와 엑셀/CSV 로 저장되며, 매일 실행하면 전일 대비 신규·돌파·탈락을 표시합니다.
2단계(저평가·펀더멘털 결합)를 붙일 수 있게 설계되어 있습니다.

> 기술적 패턴 탐지와 과거 통계를 보여주는 도구이며 투자 권유가 아닙니다.

## 빠른 시작

```bash
pip install -r requirements.txt
python -m chart_screener scan --open        # 전 종목 스캔 → output/scan_YYYYMMDD_HHMM.html 열기
```

Windows 에서는 `scan.bat` 더블클릭으로도 실행됩니다. 첫 실행은 약 2,400종목 일봉을 받느라 2~3분 걸리고,
이후에는 캐시(`cache/`)를 써서 장 마감(15:45) 후 한 번만 새로 받습니다. 장중에는 20분마다 갱신합니다.

| 명령 | 하는 일 |
|---|---|
| `python -m chart_screener scan` | 전 종목 스캔 → HTML·엑셀·CSV (`output/`), 스캔 일지 기록 |
| `python -m chart_screener scan --offline` | 네트워크 없이 캐시로만 |
| `python -m chart_screener scan --account 30000000 --risk 1` | 계좌 3천만 원, 1회 손실 1% 기준으로 수량 계산 |
| `python -m chart_screener scan --patterns vcp,cup_handle` | 일부 패턴만 |
| `python -m chart_screener analyze 005930 --open` | 한 종목의 모든 패턴 판정 근거(충족 ✔ / 미충족 ✘) |
| `python -m chart_screener market` | KOSPI·KOSDAQ 시장 방향(분산일·팔로스루데이·시장 폭) |
| `python -m chart_screener track` | 지난 스캔 후보들의 실제 5·20·60일 성과 집계 (일지 기반 사후 검증) |
| `python -m chart_screener backtest vcp` | 과거 돌파 신호 성과 (미래 참조 없는 워크포워드) |
| `python -m chart_screener backtest big_value_pullback --mode stage --stages near_pivot --step 1` | 눌림목형 백테스트 ('첫 진입만' 요약을 볼 것) |

### 일봉 이력 기간 (기본 3년 → 최대 약 10년)

기본은 3년치(760봉)를 받습니다. 더 길게 보려면 `--years` 를 붙이세요. 캐시가 짧으면 자동으로 다시 받습니다.

```bash
python -m chart_screener scan --years 10 --open
```

- 10년치: 전 종목 다운로드 약 2분 20초(최초 1회), 스캔 약 30초, 리포트 약 8MB(후보 50여 종목), 캐시 약 280MB.
- 리포트 차트는 기본 3년 보기이고 `6개월 · 1년 · 2년 · 3년 · 5년 · 10년 · 전체 · 패턴 구간` 버튼으로 바꿉니다.
- 항상 10년으로 쓰려면 `scan.bat --years 10` 으로 실행하거나 `chart_screener/config.py` 의
  `history_days` 를 `bars_for_years(10)` 으로 바꾸세요. 옵션 없이 온라인 실행하면 3년치로 다시 받습니다.
- 백테스트도 `python -m chart_screener backtest vcp --years 10` 으로 2017년부터 검증할 수 있습니다(시간은 길이에 비례).
- 10년 이전 거래량은 액면분할 미반영 원거래량이라 오래된 구간일수록 거래량 비교가 왜곡될 수 있습니다.

### 매일 자동 실행 (선택)

`scan_daily.bat` 은 멈춤·브라우저 없이 실행하고 `output/daily.log` 에 기록합니다. 장 마감 후 자동 실행하려면
명령 프롬프트에서 직접 등록하세요(경로는 본인 위치로).

```bash
schtasks /create /tn "chart_screener daily" /sc weekly /d MON,TUE,WED,THU,FRI /st 16:00 /tr "C:\경로\chart_screener\scan_daily.bat"
```

## 리포트 보는 법

- **헤더**: 시장 상태(상승 확인/상승 압박/조정, 분산일), 시장 폭(신고가−신저가, 50일선 위 비율) 스파크라인.
- **후보 탭**: 종합점수 순. 패턴 칩·단계·시장으로 거르고 `매수 검토 구간만`을 켜면 *돌파·피벗 근접*만 남습니다.
  배지(신규·단계상승·돌파·실패)는 직전 스캔 대비 변화입니다. 계좌 규모·위험%를 바꾸면 수량이 즉시 다시 계산됩니다.
- **300억 레이더 탭**: 최근 10거래일 안에 거래대금 300억↑·+7%↑ 양봉이 나온 종목과 50%선 유지 여부. 관심 목록이며 매수 신호가 아닙니다.
- **주도 업종·테마 탭**: 업종·테마별 RS 중앙값, 트렌드 템플릿 통과율, 신고가 수, 300억↑ 종목 수 순위와 대표 종목.
- **차트**: 국내 관례대로 빨강=상승, 파랑=하락. 패턴 탭을 바꾸면 윤곽(컵 곡선·VCP 수축선·박스)·피벗·손절선·돌파 마커가 바뀝니다.
- **단계**: 형성 중 → 피벗 근접(피벗 -5% 이내) → 돌파(돌파 후 5봉 이내, 매수 범위 이내) → 이격 과다 / 돌파 실패.
- **진입 계획**: `피벗 X 돌파 매수` (역지정가), `돌파 확인 — 현재가 매수`, `50%선 A~B 눌림 구간 지정가 대기`,
  `눌림 대기 (손절폭 > 10%)`. 수량 = 계좌 × 1회 위험% ÷ (진입가 − 손절가), 계좌의 20%·20일 평균 거래대금의 2% 한도.
  눌림목 손절은 **종가 기준**이고, 수량은 장중 변동을 고려해 max(손절폭, ATR) 로 계산합니다.

## 패턴

| 이름 | 패턴 | 근거 |
|---|---|---|
| `long_base_breakout` | 장기횡보 후 대량거래 장대양봉 돌파 (60~500일 박스 → +7%↑ 장대양봉, 거래량 50일 평균 5배↑, **거래대금 300억↑**) + 돌파 전 관찰 | 국내 박스권 돌파 매매 |
| `big_value_pullback` | 300억 장대양봉 후 50%선 눌림목 (Stage 2 추세 필수) | 국내 눌림목 매매 + 백테스트 |
| `vcp` | 변동성 수축 패턴 (수축 2~6회, 점진적 축소, 거래량 고갈, 52주 고점 -25% 이내 필수) | Minervini |
| `cup_handle` | 컵 앤 핸들 (+ 무핸들 컵, 형성 중 컵) | O'Neil |
| `flat_base` | 플랫 베이스 (5주↑, 깊이 15% 이내) | O'Neil |
| `double_bottom` | 더블 바텀 W (2차 저점 언더컷) | O'Neil |
| `high_tight_flag` | 하이 타이트 플래그 (8주 내 +90~100% 후 25% 이내 조정) | O'Neil·Minervini |
| `three_weeks_tight` | 3주 타이트 마감 (주간 종가 1.5% 이내 3주↑) | O'Neil |
| `pocket_pivot` | 포켓 피벗 (10일선·50일선 근처, 직전 10일 하락일 최대 거래량 초과) | Morales·Kacher |
| `canslim` | CAN SLIM 기술적 요소 N·S·L·I·M 스코어카드 (C·A 는 2단계용 플러그인) | O'Neil |
| `trend_template` | 트렌드 템플릿 8개 기준 (Stage 2) | Minervini |

각 패턴의 정확한 규칙·임계값은 `chart_screener/patterns/<이름>.py` 맨 위 설명과 `<이름>Config` 데이터클래스에
한글 주석으로 정리되어 있고, 코드 수정 없이 덮어쓸 수 있습니다.

```python
from chart_screener.config import Config
from chart_screener.patterns.vcp import VCPConfig
cfg = Config(patterns={"vcp": VCPConfig(require_near_high=True)})
```

**거래대금 300억 기준**은 `Config.big_value_threshold` 하나로 관리합니다 (장기횡보 돌파·눌림목 필수 조건,
CAN SLIM S, 300억 레이더, 종합점수 보너스).

  시장 상태(M)가 '조정'일 때는 신규 매수를 줄이세요.

  표본 밖 성과는 `track` 명령으로 앞으로 쌓이는 일지로 확인해야 합니다.
- `three_weeks_tight`(53건)·`flat_base`(53건)·`high_tight_flag`(17건)는 표본이 적어 판단을 보류합니다.

## 종합 점수

```
종합 = W × (0.55 × 대표 베이스 패턴 점수 + 0.25 × 기술적 체력(트렌드 템플릿·CAN SLIM) + 0.20 × RS) + 보너스
W(단계 가중치): 돌파 1.0 · 피벗 근접 0.95 · 형성 중 0.7 · 이격 과다 0.45 · 돌파 실패 0.15
  덮어쓰기: 300억 눌림목 50%선 근접 1.0 · 돌파 후 피벗 아래 재시험 0.6 · 묵은 돌파 0.7 · 상한가 장기횡보 돌파 0.6 ·
            CAN SLIM 이격 0.35 · 손절폭 10% 초과(지금 매수 불가) 상한 0.7 · 추세·RS 약함(RS<70 또는 TT<6/8) ×0.6 ·
            주도주(베이스 없음) 0.6, 50일선 +50% 초과 과열 0.4
보너스: 서로 다른 구조의 복수 패턴 +4~8 (같은 구조를 다른 패턴으로 읽은 중복은 제외) · 포켓 피벗 +5 ·
        최근 5일 300억↑ +5 · 업종·테마 상위 10% +5 / 하위 20% −3 · 손절폭 15% 초과 −10 · 시장 조정 −10
```

- **RS 레이팅**: IBD 방식(최근 3개월 40%, 이전 3개 분기 각 20%) 가중 수익률의 전 종목 백분위(1~99).
- **시장 방향(M)**: 분산일(−0.2%↓ & 거래량 증가, 25일 유효), 랠리 시도 4일차 이후 팔로스루데이(KOSPI +1.25%, KOSDAQ +1.5%),
  랠리 저점 이탈 시 FTD 무효, 시장 폭(신고가−신저가 10일 평균) 약화 시 점수 하향.
- **수급(I)**: 상위 60개 후보에만 네이버 투자자별 순매매를 받아 CAN SLIM I 점수에 반영하고 20일 기관·외국인 순매수를 표시합니다.
- **업종·테마**: 네이버 업종·테마 구성 종목(월 1회 갱신 캐시)으로 그룹 강도를 계산합니다.

## 데이터와 한계

- 출처: 네이버 금융 (종목 목록·일봉·투자자별 매매·업종/테마). KRX 정보데이터시스템은 로그인이 필요해 쓰지 않습니다.
- 가격은 **수정주가**, 거래량은 **원 거래량**(미수정)입니다. 베이스 안에 액면분할이 있으면 거래량 배수가 왜곡될 수 있어
  거래정지일이 패턴 구간에 있으면 경고합니다. 거래량 0 인 정지일은 자동 제거합니다. 스팩·우선주·리츠는 제외합니다.
- 과거 일별 거래대금은 `(고+저+종)/3 × 거래량` 추정치이고, 당일 값은 실제 집계치로 교체합니다.
- 장중 실행 시 마지막 봉은 미완성입니다(종목목록을 받은 시각 기준 판정). 시간대별 누적 거래량 비율(U자형)로 하루치를 환산하며
  리포트에 "장중"으로 표시됩니다. 확정 판단은 장 마감(15:45) 이후 실행을 권장합니다.
- 일봉 이력은 약 3년(750봉)이라 '역사적 신고가'는 그 범위 안의 고점입니다.

## 구조

```
chart_screener/

  indicators.py    이동평균·ATR·RS·지그재그/프랙탈 스윙
  market.py        시장 방향(M)          breadth.py  시장 폭
  sector.py        업종·테마 강도
  patterns/        패턴 탐지기 (base.py 공용 인터페이스, 모듈을 추가하면 자동 등록)
  scoring.py       종합 점수            scanner.py  전 종목 스캔·수급·레이더·포지션 계획
  journal.py       스캔 일지·전일 대비 배지·사후 성과(track)
  report/          HTML 리포트 (TradingView lightweight-charts)
  backtest.py      워크포워드 이벤트 스터디

scripts/           일괄 백테스트(bt_all.py)·기준선(baseline.py)·사전필터 검증(validate_prefilter.py)
```

### 새 패턴 추가

`chart_screener/patterns/새패턴.py` 에 `@register("이름", "표시명")` 을 붙인 `detect(ctx) -> PatternResult` 를 만들면
스캔·리포트·백테스트에 자동 포함됩니다. `trend_template.py` 가 가장 짧은 예시입니다. 베이스 패턴으로 점수에 넣으려면
`scoring.BASE_PATTERNS` 에 이름을 추가하세요.

### 2단계(저평가) 연결 지점

`ctx.info["fundamentals"] = {"eps_q_yoy": ..., "eps_annual_growth_3y": ..., "roe": ...}` 를 넣으면 CAN SLIM 의 C·A 가
채점됩니다. 수급 보강(`scanner.enrich_investor`)과 같은 방식으로 상위 후보에만 재무 자료를 붙이고, 저평가 점수는
`scoring.compute` 에 항목을 더하는 방식으로 연결하면 됩니다.
